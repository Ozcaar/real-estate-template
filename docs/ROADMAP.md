# Roadmap

## 1. MVP

The MVP focuses on building a reusable public real estate website template using static data.

### Goals

* Create the main public pages.
* Implement feature-first architecture.
* Add theme and branding system.
* Add i18n support.
* Add reusable UI components.
* Display properties from static data.
* Display developments from static data.
* Display agents from static data.
* Add contact and lead capture forms.

### MVP Pages

```txt
/
 /properties
 /properties/[slug]
 /developments
 /developments/[slug]
 /agents
 /about
 /contact
```

### MVP Features

* Landing page.
* Property listing.
* Property detail.
* Development listing.
* Development detail.
* Agents listing.
* Contact page.
* Basic search/filter UI.
* Lead forms.
* WhatsApp CTA.
* SEO metadata.
* Responsive layout.

## 2. Phase 2

Phase 2 improves the public site experience.

### Features

* Advanced property filters.
* Property comparison.
* Related properties.
* Related developments.
* Agent profile page.
* Blog or content module.
* FAQ section.
* Better SEO metadata.
* Open Graph images.
* Schema.org structured data.
* Improved animations and transitions.

## 3. Phase 3

Phase 3 prepares the system for dynamic data.

### Features

* Backend API integration.
* Real leads submission.
* CMS or admin-ready data structure.
* External image storage.
* Maps integration.
* CRM integration.
* Analytics integration.
* Environment-based agency configuration.

## 4. Phase 4

Phase 4 focuses on admin and operations.

### Features

* Admin dashboard.
* Authentication.
* Role-based access.
* Property CRUD.
* Development CRUD.
* Agent CRUD.
* Lead management.
* Image upload.
* Agency settings.
* Theme editor.
